# 🤖 Autonomous AI Coding Agent

An advanced multi-agent AI system that generates, executes, and debugs code using LLMs, Retrieval-Augmented Generation (RAG), and memory.

---

## 🚀 Features

- 🧠 Multi-agent system (Planner, Coder, Debugger)
- 🔁 Self-healing debugging loop
- ⚙️ Code execution engine (Python & Java)
- 🔍 RAG using FAISS (context-aware generation)
- 🧠 Memory system (learns from past errors)
- 🌐 Multi-language support (Python, Java)

---

## 🏗️ Architecture

User Input → Planner → RAG → Coder → Executor → Debugger → Output

---

## 🧰 Tech Stack

- Python
- LangGraph
- Groq API
- FAISS (Vector DB)
- Sentence Transformers
- Java
